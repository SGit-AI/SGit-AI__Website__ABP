write.budget.tenant

Spend money or tokens against an account it holds. Its effect is no: cannot be undone.

What this id is made of

This is not a string. It is write.budget.tenant, three nodes joined by three edges, and each of them has an address, a page and a JSON file. Follow any of them and you get the query for that word rather than a definition of it.

NodeEdgeReads as
writehas_verbthis capability has the verb write
budgetacts_onthis capability acts on budget
tenantreachesthis capability reaches tenant
moneyin_familythis capability is in the money family
nohas_undo_classthis capability has the undo class no
The gloss above is a convenience, not the definition. A node carries no inherent meaning: what write.budget.tenant is emerges from the edges traceable from it. The strongest case is tenant, where the deployment shapes that use it do not agree about what it means, and the page keeps the disagreement rather than averaging it.

Unstated is not authorised. A mandate that never mentioned a capability did not authorise it, and the delta on every example page counts it as excess and says which kind it was.
